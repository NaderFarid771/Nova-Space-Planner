# NOVA Space Planner

A responsive front-end concept for planning a small workspace. It uses a warm natural palette and CSS illustrations rather than generic stock photography.

## Features
- Responsive desktop and mobile layout
- CSS-drawn workspace illustration and floor-plan preview
- Workspace setup idea cards and design tips
- Anchor navigation between sections

## Built With
- HTML5
- CSS3

## Run Locally
Open `index.html` in a browser. No build tools are required.

## Project Structure
- `index.html` — page structure and content
- `style.css` — styling, illustrations, and responsive layout
- `README.md` — project overview

## Note
This is a fictional concept project. The planner choices are visual examples and do not dynamically change the layout.
